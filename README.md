# Desk Buddy 虚拟实验桌 · 初版

## 400 孔面包板版本

实验桌改为 30 行 × 10 孔 + 四条各 25 孔电源轨。内部连通遵循同一行 a–e / f–j 分离、四条电源轨各自连续的布局；实物若使用分段电源轨，应先核对型号。参考：https://learn.adafruit.com/breadboards-for-beginners/breadboards 。

零件按固定排针方向吸附到行位，禁止孔位重复占用和越界。点击两个空孔插入公对公杜邦线；同组金属条参与实际代码运行的接线判断。移动零件不会移动电线端点。X-ray 显示内部金属条和透明零件；点击孔位高亮电气相通的孔。

ESP32、OLED、功放排针对齐孔位；麦克风以教学转接排针接入，功放输出以端子引线接入，喇叭位于板侧支架并以两根引线接入，不能理解为原喇叭有可直接插入的排针。初版只允许沿行方向移动，以保留正确针脚方向。

作品格式升级为 version 2（记录行位和孔到孔连线），旧 JSON 不自动转换以免错误接线；原 .ino 仍可打开。新增验证 `node test-board.mjs`，涵盖孔数、行组、电源轨隔离、安装冲突、实际连通和移动后断路。未执行浏览器交互验收。

运行 `node server.mjs`，打开 http://127.0.0.1:4173 。无需 npm install。

1. 按下方提示依次连接 OLED 的 GND、VCC、SCL、SDA。
2. 点击“运行”，观察眼睛；修改坐标、半径或 delay，再次运行。
3. 可以切换三维视角、拖动和翻转零件，保存 JSON 作品、导出 Arduino .ino。

五个模型来自同项目 Blender 文件，外形按照片近似还原，尺寸不是工程测量值。

目前是教学用 Arduino 语法子集解释器，不是 ESP32 芯片仿真器或 Arduino 编译器。支持示例中的绘图、延时、简单变量和循环、串口文本、板载灯演示。数值运算采用 JavaScript 数值语义，变量作用域和整数类型并非完整 C++ 语义；文字为简化大写字体。请先以附带示例开展课程，不用它验证任意真实固件。

OLED 实际接线：GND → G，VCC → 3.3，SCL → 4，SDA → 5；Wire.begin(5, 4)，地址 0x3C。分支接线在图中连通检查。初版没有电压、电流、元件损坏或真实上传模拟。

功放、麦克风、喇叭目前支持模型摆放和接线；音频/I2S、真实麦克风输入、Scratch 模式留待后续。截图中的 ESP_I2S 程序会明确提示不支持。

验证：`node test.mjs`。当前进行了静态资源、解释执行、接线与显示缓冲区测试；尚未完成浏览器端人工交互验收。
